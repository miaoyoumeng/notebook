# OpenClaw CLI 命令树

| 命令 | 说明 |
|------|------|
| `openclaw setup` | 初始化配置 + 工作区 |
| `openclaw onboard` | 交互式向导，用于设置 Gateway 网关、工作区和 Skills |
| `openclaw configure` | 交互式配置向导（模型、渠道、Skills、Gateway 网关） |
| `openclaw config` | 非交互式配置辅助工具（get/set/unset） |
| `openclaw config get <path>` | 打印配置值（点/括号路径） |
| `openclaw config set <path> <value>` | 设置值（JSON5 或原始字符串） |
| `openclaw config unset <path>` | 删除值 |
| `openclaw doctor` | 健康检查 + 快速修复（配置 + Gateway 网关 + 旧版服务） |
| `openclaw dashboard` | 仪表盘命令 |
| `openclaw reset` | 重置本地配置/状态（保留 CLI 安装） |
| `openclaw uninstall` | 卸载 Gateway 网关服务 + 本地数据（CLI 保留） |
| `openclaw update` | 更新 OpenClaw |
| `openclaw message` | 统一的出站消息 + 渠道操作 |
| `openclaw agent` | 通过 Gateway 网关运行一个智能体回合 |
| `openclaw agents` | 管理隔离的智能体 |
| `openclaw agents list` | 列出已配置的智能体 |
| `openclaw agents add` | 添加新的隔离智能体 |
| `openclaw agents delete` | 删除智能体并清理其工作区 + 状态 |
| `openclaw acp` | 运行连接 IDE 到 Gateway 网关的 ACP 桥接 |
| `openclaw status` | 显示关联会话健康状况和最近的收件人 |
| `openclaw health` | 从运行中的 Gateway 网关获取健康状态 |
| `openclaw sessions` | 列出存储的对话会话 |
| `openclaw gateway` | 运行 WebSocket Gateway 网关 |
| `openclaw gateway call` | 调用 Gateway RPC 方法 |
| `openclaw gateway health` | 检查 Gateway 健康状态 |
| `openclaw gateway status` | 探测 Gateway 网关 RPC |
| `openclaw gateway probe` | 探测 Gateway |
| `openclaw gateway discover` | 发现 Gateway |
| `openclaw gateway install` | 服务安装 |
| `openclaw gateway uninstall` | 卸载服务 |
| `openclaw gateway start` | 启动 Gateway 服务 |
| `openclaw gateway stop` | 停止 Gateway 服务 |
| `openclaw gateway restart` | 重启 Gateway 服务 |
| `openclaw gateway run` | 运行 Gateway |
| `openclaw logs` | 通过 RPC 跟踪 Gateway 网关文件日志 |
| `openclaw system` | 系统相关命令 |
| `openclaw system event` | 将系统事件加入队列并可选触发心跳 |
| `openclaw system heartbeat` | 心跳控制（last\|enable\|disable） |
| `openclaw system presence` | 列出系统存在条目 |
| `openclaw models` | 模型管理命令 |
| `openclaw models list` | 列出可用模型 |
| `openclaw models status` | 显示模型状态 |
| `openclaw models set` | 设置默认主模型 |
| `openclaw models set-image` | 设置默认图像模型 |
| `openclaw models aliases` | 模型别名管理（list\|add\|remove） |
| `openclaw models fallbacks` | 模型回退管理（list\|add\|remove\|clear） |
| `openclaw models image-fallbacks` | 图像模型回退管理（list\|add\|remove\|clear） |
| `openclaw models scan` | 扫描可用模型 |
| `openclaw models auth` | 模型认证管理（add\|setup-token\|paste-token） |
| `openclaw models auth order` | 认证配置文件顺序管理（get\|set\|clear） |
| `openclaw memory` | 对 MEMORY.md + memory/*.md 进行向量搜索 |
| `openclaw memory status` | 显示索引统计 |
| `openclaw memory index` | 重新索引记忆文件 |
| `openclaw memory search` | 对记忆进行语义搜索 |
| `openclaw nodes` | 与已配对的节点通信 |
| `openclaw devices` | 设备相关命令 |
| `openclaw node` | 运行无头节点主机或将其作为后台服务管理 |
| `openclaw node run` | 运行节点 |
| `openclaw node status` | 查看节点状态 |
| `openclaw node install` | 安装节点服务 |
| `openclaw node uninstall` | 卸载节点服务 |
| `openclaw node start` | 启动节点服务 |
| `openclaw node stop` | 停止节点服务 |
| `openclaw node restart` | 重启节点服务 |
| `openclaw approvals` | 审批管理 |
| `openclaw approvals get` | 获取审批设置 |
| `openclaw approvals set` | 设置审批设置 |
| `openclaw approvals allowlist` | 审批白名单管理（add\|remove） |
| `openclaw sandbox` | 沙箱管理 |
| `openclaw sandbox list` | 列出沙箱 |
| `openclaw sandbox recreate` | 重新创建沙箱 |
| `openclaw sandbox explain` | 解释沙箱 |
| `openclaw tui` | 打开连接到 Gateway 网关的终端 UI |
| `openclaw browser` | 浏览器控制 CLI |
| `openclaw browser status` | 查看浏览器状态 |
| `openclaw browser start` | 启动浏览器 |
| `openclaw browser stop` | 停止浏览器 |
| `openclaw browser reset-profile` | 重置浏览器配置文件 |
| `openclaw browser tabs` | 列出浏览器标签页 |
| `openclaw browser open` | 打开 URL |
| `openclaw browser focus` | 聚焦指定标签页 |
| `openclaw browser close` | 关闭标签页 |
| `openclaw browser profiles` | 列出浏览器配置文件 |
| `openclaw browser create-profile` | 创建浏览器配置文件 |
| `openclaw browser delete-profile` | 删除浏览器配置文件 |
| `openclaw browser screenshot` | 截取屏幕截图 |
| `openclaw browser snapshot` | 获取页面快照 |
| `openclaw browser navigate` | 导航到 URL |
| `openclaw browser resize` | 调整浏览器窗口大小 |
| `openclaw browser click` | 点击元素 |
| `openclaw browser type` | 输入文本 |
| `openclaw browser press` | 按下按键 |
| `openclaw browser hover` | 悬停在元素上 |
| `openclaw browser drag` | 拖拽操作 |
| `openclaw browser select` | 选择选项 |
| `openclaw browser upload` | 上传文件 |
| `openclaw browser fill` | 填充表单字段 |
| `openclaw browser dialog` | 处理对话框 |
| `openclaw browser wait` | 等待条件 |
| `openclaw browser evaluate` | 执行 JavaScript |
| `openclaw browser console` | 查看控制台日志 |
| `openclaw browser pdf` | 生成 PDF |
| `openclaw cron` | 管理计划任务 |
| `openclaw cron status` | 显示 cron 状态 |
| `openclaw cron list` | 列出 cron 任务 |
| `openclaw cron add` | 添加 cron 任务 |
| `openclaw cron edit` | 编辑 cron 任务 |
| `openclaw cron rm` | 删除 cron 任务 |
| `openclaw cron enable` | 启用 cron 任务 |
| `openclaw cron disable` | 禁用 cron 任务 |
| `openclaw cron runs` | 查看 cron 运行记录 |
| `openclaw cron run` | 手动运行 cron 任务 |
| `openclaw dns` | DNS 相关命令 |
| `openclaw dns setup` | 广域发现 DNS 辅助工具（CoreDNS + Tailscale） |
| `openclaw docs` | 搜索在线文档索引 |
| `openclaw hooks` | 钩子管理 |
| `openclaw hooks list` | 列出钩子 |
| `openclaw hooks info` | 显示钩子详情 |
| `openclaw hooks check` | 检查钩子 |
| `openclaw hooks enable` | 启用钩子 |
| `openclaw hooks disable` | 禁用钩子 |
| `openclaw hooks install` | 安装钩子 |
| `openclaw hooks update` | 更新钩子 |
| `openclaw webhooks` | Webhook 管理 |
| `openclaw webhooks gmail` | Gmail Pub/Sub 钩子（setup\|run） |
| `openclaw pairing` | 批准跨渠道的私信配对请求 |
| `openclaw pairing list` | 列出配对请求 |
| `openclaw pairing approve` | 批准配对请求 |
| `openclaw plugins` | 管理扩展及其配置 |
| `openclaw plugins list` | 发现插件 |
| `openclaw plugins info` | 显示插件详情 |
| `openclaw plugins install` | 安装插件 |
| `openclaw plugins enable` | 启用插件 |
| `openclaw plugins disable` | 禁用插件 |
| `openclaw plugins doctor` | 报告插件加载错误 |
| `openclaw channels` | 管理聊天渠道账户 |
| `openclaw channels list` | 显示已配置的渠道和认证配置文件 |
| `openclaw channels status` | 检查 Gateway 网关可达性和渠道健康状况 |
| `openclaw channels logs` | 显示 Gateway 网关日志文件中最近的渠道日志 |
| `openclaw channels add` | 添加新渠道 |
| `openclaw channels remove` | 移除渠道 |
| `openclaw channels login` | 交互式渠道登录（仅限 WhatsApp Web） |
| `openclaw channels logout` | 登出渠道会话 |
| `openclaw security` | 安全相关命令 |
| `openclaw security audit` | 审计配置 + 本地状态中常见的安全隐患 |
| `openclaw skills` | 列出和检查可用的 Skills |
| `openclaw skills list` | 列出 Skills |
| `openclaw skills info` | 显示单个 Skill 的详情 |
| `openclaw skills check` | 就绪与缺失需求的摘要 |
| `openclaw voicecall` | 语音通话（插件；如已安装） |
