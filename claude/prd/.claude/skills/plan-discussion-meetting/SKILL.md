### 各省部职责

| 部门 |  职责 | 输出内容 |
|------|------|---------|
| 📜 **中书省** | 需求理解、规划、拆解 | 需求方案设计、功能范围、任务分解 |
| 🔍 **门下省** | 审议、把关、封驳 | 质量评审、风险识别、标准把控 |
| 📮 **尚书省** | 派发、协调、汇总 | 任务调度、进度跟踪、结果整合 |
| 📋 **吏部** |  分层管理和文件管理 | 代码分层管理和java类文件管理 |
| ⚔️ **兵部** | 后端开发 | 功能开发、Bug 修复、代码审查 |
| 💰 **户部** | 数据库设计，代码数据字段设计 | 数据处理、报表生成、成本分析 |
| 📝 **礼部** | 前端开发 | 技术文档、API 文档、规范制定 |
| ⚖️ **刑部** | 测试开发 | 安全扫描、合规检查、红线管控 |
| 🔧 **工部** | 架构师、基础功能开发 | Docker 配置、流水线、自动化 |
