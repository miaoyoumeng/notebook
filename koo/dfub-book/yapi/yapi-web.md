
## @url

@url(protocol?, host?)

随机生成一个 URL。

* protocol：指定 URL 协议。例如 http、htts或者自定义名称
* host：指定URL域名和端口号。

## @domain
作用：随机生成一个域名。
```
Random.domain()
// => "kozfnb.org"
```
## @ip

随机生成一个IP地址。

## @color
作用：随机生成一个有吸引力的颜色，格式为 '#RRGGBB'。
```
Random.color()
// => "#3538B2"
```

## @hex
作用：随机生成一个有吸引力的颜色，格式为 '#RRGGBB'。
```
Random.color()
// => "#3538B2"
```
## @rgba
作用：随机生成一个有吸引力的颜色，格式为 'rgba(r, g, b, a)'。
```
Random.rgba()
// => "rgba(242, 198, 121, 0.13)"
```
## @rgb

作用：随机生成一个有吸引力的颜色，格式为 'rgb(r, g, b)'。

```
Random.rgb()
// => "rgb(242, 198, 121)"
```

## @hsl

作用：随机生成一个有吸引力的颜色，格式为 'hsl(h, s, l)'。

```
Random.hsl()
// => "hsl(345, 82, 71)"
```
