# zookeeper集群变更过程
## 一、注意事项
1、在整个操作过程，必须保证集群的规模为“奇数”，如果集群规模为偶数必出稳定性问题。影响业务。也就是集群在扩容和缩容过程中，操作的粒度最好是两台机器，两台同时上线，两台同时下线<br/>


2、扩集群


在扩集群过程中需要注意两点：zookeeper的id不能被重复使用，如果某个id曾经使用过，而当前集群没有使用，也最好不要再使用，在实践过程中出现过无法加入集群现象。<br/>


3、缩集群


缩集群过程中，需要注意master节点，需要确定下线的节点不是master节点。命令如下：
```shell
${zookeeper_home}/bin/zkServer.sh status
```
如果下线的节点是master，则需要重启master节点，将master节点转移到其他无需下线的节点。
