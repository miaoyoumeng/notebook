# CSV 输出格式说明

抓取工具生成的 CSV 文件遵循以下规范。

## 文件基本信息

- **编码**：UTF-8
- **分隔符**：逗号（`,`）
- **引号**：字段值若包含逗号、换行符或双引号，整个字段会用双引号包裹（符合 RFC 4180）
- **表头**：第一行为列名，后续每行是一条数据记录

## 列定义

| 列名 | 数据类型 | 说明 | 示例值 |
|------|----------|------|--------|
| 时间 | 字符串 | 统计数据所属的时间周期，格式通常为“YYYY年”、“YYYY年MM月”或“YYYY年Q1”等。 | `2023年`, `2024年1-2月`, `2023年四季度` |
| 区域 | 字符串 | 统计数据覆盖的地理区域。可为“全国”、省/自治区/直辖市名称、地级市名称，或为空（表示全国汇总）。 | `全国`, `北京市`, `广东省` |
| 指标项 | 字符串 | 统计指标的名称，如国民经济核算、价格指数、人口等。不包含数值单位。 | `地区生产总值(GDP)`, `居民消费价格指数(CPI)`, `年末总人口` |
| 指标值 | 字符串 | 指标的数值，**保留原始单位和量级**（如“亿元”、“万人”、“%”）。 | `1260582.1亿元`, `102.3%`, `140967万人` |
| 来源网址 | 字符串 | 抓取该条记录时所在的完整 URL。 | `https://www.stats.gov.cn/sj/ndsj/2023/indexch.htm` |
